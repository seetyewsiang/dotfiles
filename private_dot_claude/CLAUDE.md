# Git commit messages

Follow Chris Beams' seven rules (https://cbea.ms/git-commit/) in every repo,
instead of copying the repo's existing style:

1. Separate subject from body with a blank line
2. Limit the subject line to 50 characters (72 is the hard limit)
3. Capitalize the subject line
4. Do not end the subject line with a period
5. Use the imperative mood: "If applied, this commit will <subject>"
6. Wrap the body at 72 characters
7. Use the body to explain what and why, not how

Skip the body only for trivial changes. Trailers (Resolves:, See also:,
Co-Authored-By:) go last, after a blank line.
